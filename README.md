## Setup Instructions
1. Install the dependencies

   ```sh
   npm install
   ```

   ```sh
   npm install bootstrap@5.3.8
   ```

2. Start the development server

   ```sh
   cd PierrePortfolio
   ```
   
   ```sh
   npm run dev
   ```
